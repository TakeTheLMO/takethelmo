# 페이지 명세: 공지사항

## 1. 기본 정보
| 항목 | 값 |
|---|---|
| 경로 | 목록 `/community/notices` · 상세 `/community/notices/[id]` |
| 메뉴 | 커뮤니티 > 공지사항 |
| 로드맵 단계 | 3단계 (첫 CRUD 기능 — 이후 기능의 본보기) |
| 모듈 폴더 | `features/notices/` |
| 관련 관리자 화면 | `/admin/notices` (작성·수정·게시중단) |

## 2. 목적
기관 안전관리 공지를 게시하고, 구성원이 최신 공지를 확인한다. 홈의 "최신 공지사항" 섹션에 최근 5건을 표시한다.

## 3. 접근 권한
| 역할 | 조회 | 작성 | 수정 | 게시중단 | 범위 |
|---|---|---|---|---|---|
| 비로그인 | ✗ (로그인 안내) | ✗ | ✗ | ✗ | — |
| researcher / lab_manager / lmo_manager | ✓ | ✗ | ✗ | ✗ | 소속 기관 |
| safety_admin | ✓ | ✓ | ✓ | ✓ | 소속 기관 |
| super_admin | ✓ | ✓ | ✓ | ✓ | 전체 |

비로그인 공개 여부는 `05-decisions.md` D-08 결정 전까지 **로그인 필요**로 구현한다.
비로그인 접근 시 목록 페이지는 로그인 안내 카드(로그인 버튼)를 보여 준다. 홈 섹션은 기존 빈 상태 문구 유지.

## 4. 화면 구성
### 목록 `/community/notices`
- `SectionLayout` (커뮤니티 그룹)
- 검색: 제목 키워드 (서버 쿼리 `ilike`)
- 목록: 고정 공지 먼저 → 게시일 내림차순. 컬럼: 번호(고정이면 "공지" 배지), 제목, 게시일(YYYY.MM.DD), 첨부 여부는 이번 범위 제외
- 페이지 크기 15, 하단 페이지 번호 (`?page=2&q=키워드`)
- 빈 상태: "등록된 공지사항이 없습니다."

### 상세 `/community/notices/[id]`
- 제목, 게시일, 수정일(다를 때만), 본문(줄바꿈 유지 plain text — 이번 범위에서 마크다운/HTML 렌더링 없음)
- 하단: 목록으로 버튼. 다른 기관 공지 id 로 접근 → 404

### 관리자 `/admin/notices`
- 목록(게시중단 포함, 상태 배지) + "새 공지" 버튼
- 폼: 제목(필수, 1~200자), 본문(필수, 최대 20,000자), 상단 고정(체크박스), 게시(즉시 게시 / 임시저장)
- 게시중단: status → `inactive` (확인 문구는 페이지 내 표시, 브라우저 confirm 대화상자 사용 금지)

## 5. 데이터

## 6. 상태와 이력
- 상태: `active`(게시) / `inactive`(게시중단). 승인 워크플로우 없음
- 수정 이력은 audit_logs 의 변경 전/후로 확인
