# 일상점검과 관리자 확인

## 근거와 적용 범위

2026-11-17 사용자가 제공한 `강원대학교 일상점점 캡쳐본.pptx` 3쪽의 화면을 참고했다. 2쪽의 날짜별 점검, 양호·불량·미해당, 항목별 조치사항, 확인, 월간 다운로드를 적용한다. 3쪽은 화학물질 재고 화면이므로 LMO 대장에는 보관 위치와 용기당 용량, 검색·내보내기 패턴만 반영한다. 기관 개인정보와 실제 재고는 복제하지 않는다. 보이지 않는 가스 점검 항목이나 법적 점검 주기를 추측하지 않는다.

## 사용자 흐름

- `/safety/inspections`: 한국 시간의 오늘까지 날짜 선택 → 항목별 점검 또는 일일 미해당 → 연구실명·항목별 응답·조치사항/미해당 사유 → 저장. 불량 항목은 서버가 개선조치를 생성한다.
- 점검일과 서버 등록 시각을 따로 보관한다. 같은 계정·날짜는 하나의 기록이며, 수정은 사유를 적는 정정을 사용한다. 기존 5항목 점검은 이전 양식 이력에 남는다.
- 월간 CSV는 날짜·항목별 행으로 결과와 조치사항·미해당 사유·점검자·확인자·등록 시각·템플릿 버전을 내보낸다. 기록 없는 날은 법적 미이행으로 판정하지 않는다. 미래 일자는 제외한다.
- `/management/users`: 사용자 → 점검 카테고리 → 기록 펼침 → 포털 관리자 확인 또는 사유를 적어 정정. 내용 변경과 확인은 별도 저장한다. 사용자 알림에 처리 내역을 연결한다.
- 확인은 포털의 admin 계정이 한 기록을 읽고 확인했다는 내부 기록이다. 기관 책임자의 승인·전자서명·개선조치 종결을 뜻하지 않는다. 정정하면 확인이 해제되며 기존 확인 이력과 서버 감사 기록은 보존한다.

## 데이터와 권한

- 기존 `DemoState.inspections`를 보존하고 `daily`를 선택 필드로 확장한다. `daily-v1` 항목 사본과 날짜·양식은 정정할 수 없다.
- 서버가 점검자 ID·이름·등록 시각·확인자 ID·시각·확인 대상 이력 번호를 확정한다. 소유자의 확인 위조, 이력 변경, 중복 날짜, 불완전 응답은 거부한다.
- 실제 관리자 판정은 SQLite의 활성 `username=admin`이다. 가입한 업무 역할, 브라우저 role, 기존 `super_admin` 표시만으로 타인 자료에 접근할 수 없다. 공개 가입/신규 역할 부여에서 `super_admin`과 예시 전용 이메일을 제한하되 기존 계정은 보존한다.
- 로컬 SQLite 포털의 인증/자료 보호를 적용한다. 별도로 남은 Supabase 기관 인증의 권한·RLS를 변경하거나 통합한 작업은 아니다.
- 관리자가 자료를 변경해 계정 revision이 달라지면 초안만 수정한 경우 충돌하지 않는 초안 차이를 최신 서버 상태에 합쳐 재저장한다. 같은 초안이나 업무 기록이 동시에 수정된 경우 자동 덮어쓰기하지 않고 복구 사본을 남긴다.
- 관리자 수정·확인 요청에 조회 당시 원본을 함께 전달한다. 계정 revision이 바뀌어도 대상 기록이 정확히 동일할 때만 최신 계정 상태로 재구성한다. 읽은 snapshot의 revision을 저장 트랜잭션에서 다시 확인하므로 중간에 다른 저장이 발생하면 409로 거부한다.
- 복구 사본은 최신 서버 응답을 받은 직후 실제 반영 직전에 생성한다. 이전 사본을 시간별로 보존하고, 저장 공간 부족으로 사본 생성에 실패하면 자동 재시도를 멈추며 현재 입력 다운로드를 제공한다.

## 관리대장

- `/lmo/ledger`: 선택 필드 `storageLocation`, `containerCapacity`를 추가한다. 물질명·보관위치·취득 경로 검색 및 단위 필터를 제공한다. CSV는 필터 결과를 내보낸다.
- 용기당 용량은 설명용이며 입고·사용·보관 수량으로 자동 환산하지 않는다. 정정 전후·사유를 서버에서 대조하고 기록자/시각을 확정한다.

## 검증

- 단위: 점검 날짜·응답·N/A·중복·확인 위조/무효화, 신규 불량 개선조치, CSV 수식 이스케이프, 대장 이력 변조, 첨부 소유권, 모든 비관리자 역할, 동시 저장 초안 보존.
- 브라우저: 일일 미해당 등록 → 관리자 확인 → 사용자 정정·재확인 상태, 월간 CSV, 관리자 확인과 문의 자동저장 동시 실행, 가입 역할·관리 메뉴 차단, 보관위치 검색/정정/CSV, 모바일.
- 기관 공통 연구실에 여러 계정이 동시에 기록하는 운영 모델과 지정 책임자 승인 체계는 후속 작업이다. 현재 월간 기록 범위는 계정별이다.
